# ⚡ LeetSync Squads (Browser Extension)

A 100% free, production-ready Manifest V3 browser extension for LeetCode that brings **Automatic GitHub Sync**, **Daily Streak Momentum**, **Blind 75 & NeetCode 150 Roadmaps**, and **Multiplayer Squad Rooms with 1v1 Duels**.

---

## ✨ Features & Highlights

- 🐙 **1-Click GitHub Sync**: Automatically creates and syncs every accepted LeetCode solution to your `leetcode-submissions` repository with formatted problem descriptions and complexity stats.
- 🔥 **Daily Streak & Momentum**: Authentic 7-day visual activity strip, dynamic consecutive streak calculation, and XP rewards.
- 🗺️ **Curated DSA Roadmaps**: Practice the canonical **Blind 75 (75)** and **NeetCode 150 (150)** problem sets with instant completion tracking and deterministic *Next For You* recommendations.
- ⚔️ **1v1 Multiplayer Duels**: Challenge squad mates to live coding races with live digital timer HUDs and win-rate tracking.
- 👥 **Real-Time Squad Rooms**: Join rooms via 6-character codes (e.g. `#ALGO99`), track friend streaks on live leaderboards, and send real-time `👋 Nudge` reminders.
- 🔔 **Native Desktop & Squad Solve Alerts**: Get notified when you sync solutions or when squad mates solve problems, with granular privacy toggles.
- 🌙 **Eye-Friendly Dark & Light Modes**: Seamless switch between crisp Light Mode and deep Obsidian Slate Dark Mode.
- 📝 **Problem Notes & Spaced Review**: Save personal approach notes on problem detail sheets and schedule spaced revisit reminders (+3d, +7d, +14d, +30d).

## 🚀 10-Second Installation Guide (Chrome / Brave / Edge / Arc)

1. **Download & Extract** the `leetsync-squads-v1.0.0.zip` file.
2. In your browser, navigate to:
   - **Chrome**: `chrome://extensions`
   - **Brave**: `brave://extensions`
   - **Edge**: `edge://extensions`
   - **Arc**: `arc://extensions`
3. Enable **"Developer mode"** (toggle in the top-right corner).
4. Click **"Load unpacked"** (top-left) and select the extracted folder.
5. Pin **LeetSync Squads** ⚡ to your toolbar!

---

## ⚡ 1-Minute Quick Setup

1. Click the **LeetSync Squads** extension icon in your browser toolbar.
2. On the Welcome Gateway, click **1. Open GitHub & Generate Token ↗**.
3. On GitHub, scroll down and click the green **Generate token** button (all scopes are pre-selected).
4. Copy your token (`ghp_...`), paste it into the field, and click **Unlock ⚡**.
5. LeetSync will automatically create or link your `leetcode-submissions` repo!

---

## 👥 How to Compete with Friends in Squads

1. Click the **Squad** tab in the extension.
2. Copy your room code (e.g., `#ALGO99`) and share it with your friends.
3. Your friends enter the code and click **Join**.
4. You can now see each other on the live leaderboard, race in 1v1 duels, and celebrate solves together!
